# Security

Report a vulnerability by emailing [nic@blacnova.net](mailto:nic@blacnova.net) or by opening a private GitHub security advisory on [nicholasxdavis/instatools](https://github.com/nicholasxdavis/instatools).

Do not open a public issue for a live key, token, or exploit.

We hash API keys at rest. Do not commit `.dev.vars`, `.env`, or Stripe/Brevo secrets.
